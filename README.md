# حكايتنا يا مجدى ♡

موقع ثابت بملف واحد (`index.html`) جاهز للنشر على GitHub Pages.

## النشر على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع ملف `index.html` إلى جذر المستودع.
3. افتح Settings → Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر `main` و`/(root)` ثم Save.
6. انتظر رابط الموقع الذي سيظهر في صفحة Pages.

لا يحتاج الموقع إلى مكتبات أو خادم أو إعدادات إضافية.
